The Lighthouse

Lighting the lamp…

Every request to this app is a ship. Elasticsearch logs each one, the APM agent follows its voyage, and Kibana keeps the chart. Pull a lever and watch the bay change, then search the log for a ship by name.

Control room
How the dials are read

One search on lighthouse-ships every 4 seconds: the 12 latest ships, plus two aggregations. The beam turns faster as the count of the last minute grows.

      Discover the ship log
      
          
      Create a data view on lighthouse-ships* with @timestamp, or switch Discover to ES|QL and run FROM lighthouse-ships.
      
        
      
        
      
          
      Follow voyages in APM
      
          
      Service the-lighthouse: each POST /api/ships is a transaction, with a Hold in the fog span and the Elasticsearch call inside.
      
        
      
        
      
          
      Read the wrecks
      
          
      A broken-lamp request is a failed POST /api/ships transaction (HTTP 500) in APM. Its LampError and stack trace are in the log: filter Discover on outcome: wrecked, or open a wreck in the logbook above.
      
        
      
        
      
          
      Application logs, drained
      
          
      The app also writes one JSON line per ship to stdout. A Clever Cloud log drain ships those lines to Elasticsearch, with no code: lighthouse-drain-*.
